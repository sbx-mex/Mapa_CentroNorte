CENTRO NORTE · MEJORA REGIONAL 4.0

APLICAR
1. Extrae el ZIP.
2. Copia su CONTENIDO en la raíz del proyecto Mapa_CentroNorte existente.
3. Conserva las carpetas y reemplaza los archivos coincidentes.
4. Sube el contenido a GitHub, incluyendo .github/workflows/ci.yml.
5. Espera la validación y publicación de Pages. Comprueba Base validada.

El ZIP es incremental: conserva cms/, las librerías y la cartografía existentes.
No subas únicamente el ZIP ni lo publiques dentro de otra subcarpeta.

USAR
Selecciona una tienda. Elige Región propuesta. Guarda.
Para tomar una externa: elige Centro Norte.
Para ceder una propia: elige otra región.
Mostrar DM / Ocultar DM activa o apaga los colores por responsable.
Las casillas y el botón de área permiten proponer varias tiendas juntas.
Revisar propuesta muestra el balance completo; Exportar descarga el detalle.

La entrega incluye 45 pruebas automatizadas y revisión de la navegación.
El resultado de GitHub Actions se confirma después de subir la mejora.
Ver README.md para las instrucciones completas.
