CENTRO NORTE · FONDO GEOGRÁFICO 4.1

Aplicar sobre la mejora regional 4.0 ya instalada.

1. Extrae el ZIP.
2. Copia su CONTENIDO en la raíz del proyecto Mapa_CentroNorte existente.
3. Conserva las carpetas y reemplaza los archivos coincidentes.
4. Sube los archivos extraídos a GitHub y espera validación y publicación.

CAMBIO
El fondo tiene cinco zonas de referencia: Centro, Norte, Poniente, Sur y Oriente.
Los límites municipales son de INEGI; la agrupación por orientación es una
referencia ajustable, no una regionalización oficial de INEGI.

Los colores se aplican únicamente al fondo. Mostrar/Ocultar DM modifica los
pines. Las regiones internas Starbucks se conservan para tomar o ceder tiendas.

Fondo geográfico permite controlar intensidad, nombres y zona del municipio.
Pintar solo este fondo no cambia tiendas, DM, regiones internas ni balance.
Ver territorio completo encuadra las cinco zonas; Centrar tiendas visibles
regresa a las tiendas.

El ZIP incluye únicamente archivos nuevos o modificados. Conserva Excel,
bases, librerías y cartografía. No necesitas ejecutar Python para aplicarlo.

Validación: 20 pruebas Python + 30 JavaScript y revisión en navegador.
La ejecución en GitHub Actions se confirma al terminar la carga.
